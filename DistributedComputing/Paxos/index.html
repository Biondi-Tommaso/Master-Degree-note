01

THE PROBLEM

What does “agree” mean?

Imagine three machines that must agree on a single decision: “Write X.” Messages can be delayed, duplicated, reordered, or lost. A machine can also crash.

Paxos is not trying to make the network reliable. It makes a stronger promise: if a value is chosen, a different value can never be chosen later.

Key idea Consensus is about agreement on one value, not about making every message arrive.

04

PHASE 1

Prepare is a promise about the future.

Suppose proposer P1 chooses proposal number 11. It sends prepare(11) to the acceptors.

if n > promisedpromise(11)“I won’t accept anything smaller than 11.”

Each promise also reports the highest proposal the acceptor has already accepted, if any. That single detail is what lets a later proposer preserve an earlier decision.

05

PHASE 2

Accept carries the value.

Once P1 has promises from a majority, it sends accept(11, X). The value is X only if the promises contained no earlier accepted value.

Case ANo accepted value

P1 may propose its own value.

Case BOlder accepted value exists

P1 must carry forward the value attached to the highest accepted proposal it learned about.

06

THE INTERESTING PART

Now break the happy path.

Paxos becomes memorable when two proposers race, or an acceptor disappears. The same rule still holds: a new proposal can move forward, but it cannot forget a value that a previous quorum may have chosen.

07

FROM ONE DECISION TO A LOG

Multi-Paxos changes the rhythm.

Classic Paxos decides one value at a time. Real replicated state machines need a sequence of values. Multi-Paxos keeps a stable leader/proposer and reuses its Phase 1 preparation across many log slots, avoiding a full round of prepare messages for every command.

THE ONE THING TO REMEMBER

A quorum intersection is the bridge between the past and the future.

With three acceptors, any two form a quorum. Any later quorum must overlap an earlier quorum in at least one acceptor. That overlap is where the memory of the earlier decision survives.
