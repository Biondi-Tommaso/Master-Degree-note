The gradient points uphill in the input plane
01 / THE IDEA

A function turns a point into a height.

For two variables, f(x,y) takes a location (x,y) and returns one number. If you draw every possible location above a flat plane, that number becomes height. You get a surface: a landscape made by the function.

At one point on that landscape, there are many directions you could move. The question is: which direction makes the height increase fastest?

Key ideaThe gradient answers that question. It lives in the x–y input space; it tells you how to move through the domain, not where the camera should look.
02 / BUILD IT

Two local slopes become one vector.

Along xfₓ = ∂f / ∂x

Hold y fixed. This is the rate of change when you move east–west.

Along yfᵧ = ∂f / ∂y

Hold x fixed. This is the rate of change when you move north–south.

Collect∇f = ⟨fₓ, fᵧ⟩

The two directional slopes become one vector in the domain.

Gradient at a point∇f(x,y) = ⟨ ∂f/∂x, ∂f/∂y ⟩The vector points toward greatest increase. Its magnitude is the maximum rate of increase at that point.

04 / THE RECIPE

How to determine the gradient, every time.

Step 1 — Differentiate with respect to x.

Treat y as a constant.

f(x,y) = x² + 3xy + sin(y)
fₓ = 2x + 3y
Ask: “How fast does f change if only x moves?”

Step 2 — Differentiate with respect to y.

Treat x as a constant.

f(x,y) = x² + 3xy + sin(y)
fᵧ = 3x + cos(y)
Ask: “How fast does f change if only y moves?”
Step 3 — Evaluate, then collect.∇f(x,y) = ⟨fₓ(x,y), fᵧ(x,y)⟩At a chosen point (a,b), compute both numbers and substitute them into the vector.
Step 4 — Keep only direction when needed.u = ∇f / ||∇f||Normalization turns the gradient into a unit vector. It preserves direction and removes magnitude.
Why the vector is perpendicular to contoursA level set keeps f constant. Moving along it produces zero change. The gradient is orthogonal to every direction with zero directional change, so it meets a level set at a right angle.
05 / PRACTICE

Change the surface. Keep the method.

The workflow never changes: differentiate → evaluate → collect → normalize if direction alone is needed.

GeneralizationFor n variables, the same idea produces an n-dimensional vector: ∇f = ⟨∂f/∂x₁, …, ∂f/∂xₙ⟩.

The gradient is the first-order summary of how a scalar field changes around one point. Its direction gives steepest ascent, and its magnitude gives the maximum directional derivative.
